# Claude Link — 分段实施计划（跨会话版）

## Context

构建 Claude Code CLI 任务调度桌面应用。Electron + Vue 3 + TypeScript，通过子进程管道连接 CLI，三栏布局（会话列表 + 聊天区 + 任务队列）。

**使用方式**：每次开新会话时，告诉 Claude "执行 Segment X"，Claude 会读取此计划并实施。每个 Segment 预估了时间和 token 成本。

---

## 技术栈

Electron 35+ / Vue 3.5 + TypeScript 5.7 / electron-vite 3 / better-sqlite3 / electron-store + safeStorage / Pinia 3 / vue-draggable-plus / markdown-it / highlight.js

## 数据模型（SQLite）

```sql
CREATE TABLE sessions (
  id TEXT PRIMARY KEY, name TEXT NOT NULL, cli_session_id TEXT,
  model TEXT NOT NULL DEFAULT 'claude-sonnet-4-6',
  working_dir TEXT, permission_mode TEXT DEFAULT 'default', max_turns INTEGER DEFAULT 200,
  created_at TEXT NOT NULL DEFAULT (datetime('now')),
  updated_at TEXT NOT NULL DEFAULT (datetime('now'))
);

CREATE TABLE messages (
  id TEXT PRIMARY KEY, session_id TEXT NOT NULL REFERENCES sessions(id) ON DELETE CASCADE,
  role TEXT NOT NULL CHECK(role IN ('user','assistant','system','tool')),
  content TEXT NOT NULL, raw_event TEXT, event_type TEXT,
  cost_usd REAL, duration_ms INTEGER, parent_task_id TEXT,
  created_at TEXT NOT NULL DEFAULT (datetime('now'))
);
CREATE INDEX idx_messages_session ON messages(session_id, created_at);

CREATE TABLE tasks (
  id TEXT PRIMARY KEY, session_id TEXT NOT NULL REFERENCES sessions(id) ON DELETE CASCADE,
  prompt TEXT NOT NULL,
  status TEXT NOT NULL DEFAULT 'pending' CHECK(status IN ('pending','queued','running','completed','failed','cancelled')),
  sort_order INTEGER NOT NULL DEFAULT 0,
  result TEXT, cost_usd REAL, duration_ms INTEGER, error_message TEXT,
  started_at TEXT, completed_at TEXT,
  created_at TEXT NOT NULL DEFAULT (datetime('now')),
  updated_at TEXT NOT NULL DEFAULT (datetime('now'))
);
CREATE INDEX idx_tasks_session_order ON tasks(session_id, sort_order);
CREATE INDEX idx_tasks_status ON tasks(status);
```

## 核心模块设计要点

### 进程管理器 (`process-manager.ts`)
- **聊天模式**：`claude -p --input-format stream-json --output-format stream-json --verbose --include-partial-messages --model <model> [--resume <sid>]`
- **任务模式**：`claude -p <prompt> --output-format stream-json --verbose --include-partial-messages --model <model> [--resume <sid>]`
- 进程注册表 `Map<sessionId, ChildProcess>`，从 CliInitEvent 获取 session_id 供后续 --resume

### 流解析器 (`stream-parser.ts`)
- stdout 按 `\n` 分割 → `JSON.parse()` → CliEvent → `webContents.send('chat:event', ...)`
- stream_event 50ms debounce 批量发送

### 任务队列引擎 (`task-queue-engine.ts`)
- 状态机：`IDLE → RUNNING → WAITING(60s) → RUNNING → ... → IDLE`
- 控制：start / pause / resume / interrupt / delete / reorder
- 任务共享上下文 via --resume session_id
- 倒计时 UI + 跳过按钮

## 会话衔接策略

每次新会话开始执行某个 Segment 时，说：**"执行 Segment X"**。

Claude 会：
1. 读取此计划文件
2. 检查 `src/` 目录确认之前的 Segment 已完成
3. 执行当前 Segment 的所有步骤
4. 运行验证
5. 告诉你可以进入下一个 Segment
